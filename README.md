# Vis in Hand

VR-сумісність для гравців **Vivecraft** у Minecraft 1.21.1 (NeoForge). Мод адаптує під VR кілька модів;
кожна частина вмикається **лише якщо відповідний мод встановлено**. Обов'язковий тільки Vivecraft.

| Мод | Що робить Vis in Hand |
| --- | --- |
| **Thaumaturge** | жезл, таумометр та інші інструменти цілять контролером; панель фокусів замість кругового меню мишею |
| **Industrial Craft 2: Nostalgia** | шахтарський лазер стріляє з контролера; рух стіком уперед = клавіша «вперед» для ранця й квантових поножів |
| **CC: Tweaked** | VR-клавіатура сама відкривається з екраном комп'ютера, черепашки чи кишенькового комп'ютера |

Гравці без VR нічого не помітять: для них лишається стара поведінка.

Перевірено (21.11.2026) з Thaumaturge 1.1.0, IC2 Nostalgia 21.1.0, CC: Tweaked 1.120.2, Vivecraft 1.3.15,
NeoForge 21.1.267: гра стартує, усі хуки вбудовуються; без Thaumaturge мод теж працює. Сам VR-геймплей
у шоломі ще не тестувався.

## Thaumaturge

### Прицілювання контролером

| Що | Де в Thaumaturge |
| --- | --- |
| Заклинання з жезла: звідки летять і куди | `SpellTarget.origin` (1.1.0), `SpellTarget.wandOrigin` (новіші) |
| Ефекти на кінчику жезла | `SpellTarget.visualWandOrigin` |
| Таумометр: сканування й підказка аспектів | `ScanRaycastHelper.performRaycast`, `ScanningManager.blockStack` |
| Висмоктування вузла, очищення кристала | `ItemWand.targetedNode`, `ItemWand.refineTarget` |
| Фокус «Архітектор», Елементальна лопата | `traceAnchor` |
| Налаштування сторони есенцієвої труби | `BlockEssentiaTransport.traceLook` |

Рука — та, у якій предмет Thaumaturge (спершу основна); для жезла — рука, якою кастують.

### Панель фокусів

У VR кнопка «Change focus» відкриває **панель фокусів** замість кругового меню, яке керується мишею.
Панель — звичайний екран Minecraft, тож Vivecraft показує її як плаский екран: цілишся променем і тиснеш курок.

- по колу — усі фокуси з інвентаря, сумок для фокусів (і сумок у слотах Curios); поточний у золотій рамці;
- у центрі — «Зняти фокус» (раніше Shift+F);
- «Розмір області» / «Вісь області» — керування фокусом «Архітектор» (раніше G / Ctrl+G);
- при виборі — коротка вібрація контролера.

## Industrial Craft 2: Nostalgia

- **Шахтарський лазер** (`ItemToolMiningLaser`) бере позицію й напрямок з контролера, у якому лежить лазер,
  а не з голови — в усіх режимах, включно з кліком по блоку.
- **Рух стіком.** IC2 надсилає серверу клавішу «вперед» для реактивного ранця та квантових поножів. У VR
  ходять стіком, тож поки ти у VR, стік уперед (більш ніж на 30%) теж вважається натиснутою клавішею.
- Клавіші IC2 (Alt, Boost, Mode Switch, Side Inventory, HUD, Gravi) прив'язуються до кнопок — див. нижче.

## CC: Tweaked

Комп'ютери читають клавіші напряму з екрана, а не з текстового поля, тож Vivecraft сам не показує клавіатуру.
Vis in Hand відкриває VR-клавіатуру разом з екраном комп'ютера, черепашки чи кишенькового комп'ютера
і ховає її, коли екран закривається. Вимкнути/перезапустити й зупинити програму — кнопки збоку екрана
комп'ютера (замість утримання Ctrl+S / Ctrl+R / Ctrl+T).

## Як прив'язати кнопки

Клавіші модів Vivecraft сам додає в набір дій **Mod**:

- **SteamVR**: Settings → Controllers → Manage Controller Bindings → Minecraft (Vivecraft) → Custom →
  вкладка «Mod» → призначити «Change focus», «Open Thaumonomicon», «Mode Switch Key» (IC2) тощо;
- або без SteamVR: у грі Vivecraft → Radial Menu → додати ці дії в кругове меню Vivecraft.

## Збірка

```
./gradlew build
```

Для компіляції потрібні jar Thaumaturge та IC2 Nostalgia у `libs/` (локально, не комітяться й не входять у мод).
CC: Tweaked для компіляції не потрібен.

`./gradlew runSelftest` — автотест: відкриває панель фокусів (якщо є Thaumaturge), зберігає
`run/screenshots/visinhand_selftest.png` і сам закриває гру (максимум через 2 хв). Змінені класи
вивантажуються в `run/.mixin.out` — там видно, куди стали хуки (`javap -c`, шукати `visinhand$`).

У `run/mods` для тесту: Vivecraft + потрібні моди (Thaumaturge із Curios і Lithostitched, IC2, CC: Tweaked).

Jar: `build/libs/visinhand-0.3.0.jar`. Ставиться і на клієнт, і на сервер (сервер потрібен для прицілювання).

## Як влаштовано

Код інших модів **не копіюється**: міксини (`@Pseudo`) чіпляються до їхніх класів за назвою, а позу
контролера беремо з публічного API Vivecraft (`org.vivecraft.api`). Клієнтські частини реєструються лише
тоді, коли їхній мод встановлено (`VisInHandClient`).
