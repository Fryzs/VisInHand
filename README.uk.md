Багато технічних і магічних модів розраховані на мишу й клавіатуру: цілять туди, куди дивиться **голова**,
відкривають кругові меню, що керуються **мишею**, і чекають, що ти будеш **друкувати**. У VR це незручно.
Vis in Hand виправляє це для модів нижче. Кожна частина вмикається **лише якщо відповідний мод встановлено**;
обов'язковий тільки Vivecraft. Гравці без VR нічого не помітять.

| Мод | Що змінюється у VR |
| --- | --- |
| 🔮 **Thaumaturge** | Жезл, таумометр та інші інструменти цілять **контролером**; **панель фокусів** замість кругового меню мишею |
| ⚙️ **Industrial Craft 2: Nostalgia** | **Шахтарський лазер** стріляє з руки; **стік** уперед = клавіша «вперед» для ранця й квантових поножів |
| 💻 **CC: Tweaked** | **VR-клавіатура** сама відкривається з екраном комп'ютера, черепашки чи кишенькового комп'ютера |

## ✨ Можливості

### 🔮 Thaumaturge

**Прицілювання контролером** — усе, що раніше йшло за головою, тепер іде за рукою з інструментом:

| Що | Де в Thaumaturge |
| --- | --- |
| Заклинання з жезла: звідки летять і куди | `SpellTarget.origin` (1.1.0), `SpellTarget.wandOrigin` (новіші) |
| Ефекти на кінчику жезла | `SpellTarget.visualWandOrigin` |
| Таумометр: сканування й підказка аспектів | `ScanRaycastHelper.performRaycast`, `ScanningManager.blockStack` |
| Висмоктування вузла, очищення кристала | `ItemWand.targetedNode`, `ItemWand.refineTarget` |
| Фокус «Архітектор», Елементальна лопата | `traceAnchor` |
| Налаштування сторони есенцієвої труби | `BlockEssentiaTransport.traceLook` |

**Панель фокусів** — у VR «Змінити фокус» відкриває пласку панель, у яку цілишся променем контролера:

- по колу — усі фокуси з інвентаря й сумок для фокусів (і зі слотів Curios), поточний у золотій рамці;
- у центрі — **«Зняти фокус»** (раніше Shift+F);
- **«Розмір області»** / **«Вісь області»** для фокуса «Архітектор» (раніше G / Ctrl+G — у VR немає клавіатури);
- при виборі — коротка вібрація контролера.

### ⚙️ Industrial Craft 2: Nostalgia

- **Шахтарський лазер** бере позицію й напрямок з контролера, у якому лежить, в усіх режимах, зокрема
  при кліку по блоку.
- **Стік = «вперед».** IC2 надсилає серверу клавішу «вперед» для реактивного ранця й квантових поножів. У VR
  ходять стіком, тож поки ти у VR, стік уперед більш ніж на 30% вважається натиснутою клавішею.
- Власні клавіші IC2 (Alt, Boost, Mode Switch, Side Inventory, HUD, Gravi) можна прив'язати до кнопок — див. нижче.

### 💻 CC: Tweaked

Комп'ютери читають клавіші напряму з екрана, а не з текстового поля, тож Vivecraft сам не показує для них
клавіатуру. Vis in Hand відкриває VR-клавіатуру разом з екраном комп'ютера, черепашки чи кишенькового комп'ютера
і ховає її, коли екран закривається. Вимкнути, перезапустити й зупинити програму — кнопки збоку екрана
комп'ютера, тримати Ctrl+S / Ctrl+R / Ctrl+T не треба.

## 🎮 Прив'язка кнопок контролера

Vivecraft додає всі клавіші модів у свій набір дій **Mod**:

- **SteamVR:** Settings → Controllers → Manage Controller Bindings → Minecraft (Vivecraft) → Custom → вкладка
  *Mod* → призначити *Change focus*, *Open Thaumonomicon*, *Mode Switch Key* з IC2 тощо;
- **або в грі:** налаштування Vivecraft → Radial Menu → додати ці дії в кругове меню самого Vivecraft.

NeoForge 21.1.267: гра стартує, усі хуки вбудовуються, мод працює й без Thaumaturge. Гру в шоломі ще не тестували.

## 🛠️ Збірка

```
./gradlew build
```

Для компіляції потрібні jar Thaumaturge та IC2 Nostalgia у `libs/` (лише локально: не комітяться й не входять у
мод). CC: Tweaked для компіляції не потрібен.

`./gradlew runSelftest` відкриває панель фокусів (якщо є Thaumaturge), зберігає
`run/screenshots/visinhand_selftest.png` і сам закриває гру (максимум через 2 хвилини). Змінені класи
вивантажуються в `run/.mixin.out`, тож `javap -c` покаже, куди саме стали хуки (шукай `visinhand$`).

## 🧩 Як це влаштовано

Код інших модів не копіюється: міксини `@Pseudo` чіпляються до їхніх класів за назвою, а позу контролера мод бере
з публічного API Vivecraft (`org.vivecraft.api`). Клієнтські частини реєструються лише тоді, коли їхній мод
встановлено (`VisInHandClient`).
